# CalcGPT - AI-Powered Calculator

A modern calculator application that combines traditional arithmetic with AI-powered explanations using Google's Gemini API.

## Features

- Clean, modern interface
- Basic arithmetic operations
- AI-powered explanations and help
- Support for complex mathematical concepts
- Educational tips and insights
- Web-ready design

## Requirements

- Python 3.x
- Required packages:
  - google-generativeai
  - tkinter
  - ttkthemes

## Installation

1. Clone the repository:
```bash
git clone https://github.com/[your-username]/calcgpt.git
cd calcgpt
```

2. Create a virtual environment:
```bash
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate
```

3. Install dependencies:
```bash
pip install google-generativeai ttkthemes
```

4. Run the calculator:
```bash
python main.py
```

## Usage

1. Enter a mathematical expression using the calculator buttons or keyboard
2. Press '=' for basic calculations
3. Click 'AI Help' for detailed explanations and mathematical insights
